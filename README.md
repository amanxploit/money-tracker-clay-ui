# 💎 LumiFinance // Premium Money Manager

LumiFinance is a high-performance, mobile-first money management web application designed with a **Liquid Glass** aesthetic. It allows users to track income, manage expenses, and maintain a financial overview with a native-app experience.

## ✨ Key Features

- **🚀 PWA Enabled**: Installable on iOS and Android. Works entirely **offline** thanks to Service Worker caching.
- **🎨 Liquid Glass UI**: Modern fintech design using `backdrop-filter`, deep gradients, and high-saturation glassmorphism.
- **💰 Smart Tracking**: 
  - Real-time balance calculation.
  - Separate Income and Expense logging.
  - Categorized transaction history.
- **💾 Data Sovereignty**: 
  - No backend required. Uses `localStorage` for instant loading.
  - **Backup & Restore**: Export your financial data to a `.json` file and import it later to prevent data loss.
- **📱 Mobile-First UX**: Designed for one-handed usage with a symmetrical "Integrated Dock" navigation.

## 🛠️ Tech Stack

- **Frontend**: HTML5, Tailwind CSS
- **Logic**: Vanilla JavaScript (ES6+)
- **Persistence**: Browser LocalStorage
- **PWA**: Web App Manifest, Service Workers

## 🚀 Installation & Setup

Since this is a client-side application, there is no complex installation.

1. **Clone the repository**:
   ```bash
   git clone https://github.com/amanxploit/money-tracker-clay-ui
   ```
2. **Install on Mobile**:
    Open the hosted URL in Chrome (Android) or Safari (iOS).
    Tap "Add to Home Screen".
